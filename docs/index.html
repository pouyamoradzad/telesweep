Features

Everything you need to take out the trash

Years of dead bots, abandoned channels and deleted accounts add up. TeleSweep audits all of it — and shows its work.

⚖️

Strict rules engine

Every dialog gets a 0–100 risk score with per-rule evidence. A chat is flagged only when the score reaches the threshold and at least two independent rules agree — never a single hunch.

🧪

Dry-run by default

Every interface — CLI, terminal UI, web UI — shows exactly what would happen before anything changes. Real deletion always needs an explicit, deliberate confirmation.

🛡️

Hardcoded protections

Saved Messages, pinned chats and real contacts are never deleted — enforced at the code level and re-checked in the action layer as a second line of defense.

🔐

Credentials encrypted

API keys are encrypted at rest with AES-256-GCM; the key is derived from your passphrase via PBKDF2-HMAC-SHA256 with 200,000 iterations. Logs are sanitized of phone numbers, codes and tokens.

📊

Detailed reports

JSON, CSV and HTML reports with per-dialog reasons, risk scores and outcomes. Keep the audit trail of exactly what was cleaned and why.

🌍

Truly international

Ten locales out of the box — English, Arabic, German, Spanish, Persian, French, Portuguese, Russian, Turkish, Chinese — with full right-to-left support in the terminal, web and reports.

How it works

From install to clean in four steps

No accounts, no sign-ups. Everything happens on your own machine.

1

Get API keys

Grab your personal api_id and api_hash from my.telegram.org. They never leave your computer.

2

Initialize

python main.py init encrypts your credentials with a passphrase you choose. Stored with 0600 permissions.

3

Scan (read-only)

python main.py scan scores every dialog and writes reports. Nothing is deleted — this is pure audit.

4

Review & confirm

python main.py review opens the terminal UI. Select what to remove, confirm, and TeleSweep does the rest — rate-limited and FloodWait-safe.

The deletion contract

Six rules. No guesses. Always justified.

A dialog is flagged only when both hold: risk score ≥ 80 (configurable) and at least min_evidence (default 2) independent rules fired. The one exception is a deleted account — an absolute verdict.

RuleFires when…Weight
deleted_account The account was deleted from Telegram — the person is gone and the dialog is pure dead data. 100 · absolute
scam_spam_flag Telegram flagged the account as scam/fake, or the name and bio match scam and spam keyword patterns. 80–90
dead_bot A bot that has sent no message in the inactivity window (default 180 days). 85
abandoned_channel A channel or group inactive for the inactivity window; weight scales with how little history it has. 70–80
one_way_spam >80% of messages are one-way from them with links or ads, and you have not replied in 90 days. 65–75
empty_chat Zero messages, or just one or two very old ones. 70–72
Security first

Your account, your machine, your rules

  • ✓Local only. The only network calls go to Telegram's own MTProto servers. The web UI binds to 127.0.0.1 and nothing else.
  • ✓Encrypted at rest. AES-256-GCM with a PBKDF2-HMAC-SHA256 key derived from your passphrase (200,000 iterations).
  • ✓Sanitized logging. A filter strips phone numbers, login codes, API hashes, bot tokens and session strings from every log record.
  • ✓Rate limiting + FloodWait handling with per-dialog timeouts, so a scan can never get your account restricted.
  • ✓Constant-time token comparison for the web UI, and a one-time token printed in your terminal.
  • ✓No telemetry, no analytics, no uploads of any kind — ever.

Installation

Running in under a minute

Requires Python 3.9 or newer. No compilation, no containers.

# 1 · clone $ git clone https://github.com/pouyamoradzad/telesweep.git $ cd telesweep # 2 · install dependencies $ pip install -r requirements.txt # 3 · add your Telegram API keys (encrypted on disk) $ python main.py init # 4 · scan — nothing is deleted, this is read-only $ python main.py scan # 5 · review in the terminal UI, then decide $ python main.py review # web UI instead? localhost only, one-time token: $ python main.py web

Prefer a package? Install with pip install telesweep and run telesweep from anywhere.
